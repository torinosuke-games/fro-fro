# Frozen Frontier

学ぶ熱で雪に閉ざされた町を育てるブラウザーゲーム。`index.html` を開くだけで動きます。

名前・学年・キャラクターを設定したら「学習する」→「教科」を選びます。今回追加した図解つき100問は、小学4年の算数で使えます。

変更内容・操作・検証結果は [RENEWAL.md](RENEWAL.md)、全100問の内容は [QUESTIONS_100.md](QUESTIONS_100.md) を参照してください。

公開先：[Frozen Frontier](https://torinosuke-games.github.io/fro-fro/)（GitHub Pages・mainブランチ）。既存のプレイ記録を引き継ぐリニューアル版です。

試作の「雪原の冒険」は、町の「雪原へ出発」から遊べます。仲間3人との編成、クイズ式コマンドバトル、次の町までの旅を追加しました。操作と試作範囲は [ADVENTURE_PROTOTYPE.md](ADVENTURE_PROTOTYPE.md) を参照してください。
