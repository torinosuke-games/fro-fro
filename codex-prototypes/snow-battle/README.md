# 雪の峠の戦い — 独立した戦闘試作

既存ゲームとフィールド試作のファイルを変更せず、雪山のターン制コマンドバトルを評価するための一式です。試作の保存・育成・進行は本編に反映されません。

## 開き方

- このフォルダーを静的HTTP/HTTPSサーバーで配信し、`index.html` を開きます。ビルド・ログインは不要です。例：リポジトリのルートで `python -m http.server 8000` を実行し、`http://localhost:8000/codex-prototypes/snow-battle/` へアクセスします。
- `review.html` は画面の比較・評価用入口です。
- スマホには、このフォルダーをHTTPSで静的配信したURLを使います。戦闘試作用に案内されたURLを使ってください。フィールド用の公開URLとは別です。
- ZIPはランタイムのWebP画像とコード、レビュー入口、説明資料を含みます。比較用の最終スクリーンショット4枚も含みます。生成元PNG、検証スクリプト、その他のスクリーンショットはリポジトリ側だけに残します。

## 評価する流れ

1. 仲間のカードをタップし、攻撃・固有技・防御・回復薬を予約します。「おすすめの作戦」「全員たたかう」でも変更できます。
2. 「この作戦で問題へ」で、そのターンの問題を表示します。選択肢は確定前なら選び直せます。時間制限はありません。
3. 「この答えにする」で、問題・自分の答え・正解・解説を表示します。「わからない」も必ず同じ確認画面へ進みます。
4. 「解答を確認した · 行動する」を押してから、仲間と敵の行動を解決します。解答画面は自動で閉じません。
5. 次のターンも出題と解答表示が必要です。敵を倒せるターン、敗北するターンも省略しません。「記録」で全ターンを振り返れます。

## オートで戦う

戦場の左上にある「オート OFF」を押すとONになります。仲間のHP・MPから攻撃技、回復、かばうを予約し、そのターンの問題まで進みます。行動が終わると1.5秒後に次の作戦を選び、次の問題で停止します。

問題の回答と「解答を確認した · 行動する」は毎ターン手動です。ヒントや「わからない」も使えます。オートは正解を選んだり、解説を自動で閉じたりしません。いつでもOFFにできます。問題・解答中にOFFにした場合は今の予約を維持し、次のターンから手動で作戦を選びます。勝利・敗北では停止し、再戦はOFFから始まります。ヘルプ・履歴表示中と非表示タブ中は自動進行を止めます。

## 提案の中心

雪の背景と立ち絵は静止画を中心に、行動中だけ短く動かします。上部はTURN・進行表示・記録・ヘルプを一行にまとめています。戦場の高さは開始時に、最も長い作戦説明まで収まる領域を確保して決めます。その後は仲間の選択、問題、解説、行動、次のターンで高さやキャラクターの配置を変えません。画面サイズ・向きの変更時には再計算します。解説・問題・履歴が長い場合は下のパネル内をスクロールし、決定ボタンはパネル下部に残します。横画面・PCは戦場と操作を左右に分けます。HP/MP・予約した技・消費予定が仲間のカードに残り、攻撃を選び直すための往復を減らします。

正解は与えるダメージ1.5倍・受けるダメージ半分。誤答でも予約した行動は行います。MP・回復薬は予約時に消費しません。敵の次回行動予告は表示しません。演出×2、OSの動きを減らす設定、説明ダイアログ・非表示タブ中の一時停止に対応します。

## 試作の範囲

4人と敵1体、固定された試作用ステータス、回復薬2個、小学4年相当の算数12問です。問題は試作用に作成したサンプルで、教材監修・学年網羅はしていません。12ターンを超えると問題を循環します。敵行動・技・対象指定・戦闘バランスは本編の仕様を置き換える提案ではありません。履歴はページを閉じると消えます。

## 検証

戦闘機能の検証は `qa/results.json` と `qa/verify.cjs`、作戦操作のスクロール不要化の検証は `qa/layout-results.json` と `qa/layout.cjs` に記録しています。320×568、390×844、844×390、768×1024、1365×900で横溢れ・主操作ボタン・4択への到達を確認しました。小画面では問題パネル内を縦スクロールできます。

オートの作戦選択・次ターン進行・ON/OFF・問題と解答での停止、毎ターンの解答確認、正誤・未回答、MPと回復薬の予約、勝敗、履歴、非表示時停止、動きを減らす設定、本編への依存なし・保存領域への書き込みなしを検証しています。LinuxのChromiumによる画面・タッチ操作の模擬検証です。iPhone Safari／Android実機の動作速度、発熱、ブラウザーの可変アドレスバーは未確認です。HTML直接起動は、この検証環境のブラウザーポリシーが `file://` を拒否したため未検証です。HTTP配信で検証しました。
