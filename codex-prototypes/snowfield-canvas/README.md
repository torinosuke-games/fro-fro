# 雪あかりの峠 — フィールド描画・操作の試作

既存の Frozen Frontier に触れずに作った、雪山フィールドの独立した評価用ページです。主人公は1人表示、画面上の編成表示は4人です。生成画像の地形素材とCanvas 2Dを使っています。

## 開き方

- **試す**：このフォルダーの `index.html` をブラウザーで開きます。ビルド、サーバー、外部ライブラリ、外部画像配信は不要です。
- **比較する**：`review.html` に現行版・初回試作・最終版の画面を並べています。
- **別の環境へ渡す**：`snowfield-trial.zip` は実行ファイル・実行用画像・説明書だけをまとめたものです。展開後 `index.html` を開いてください。原画・測定用スクリプト・比較画像はリポジトリ側に残しています。
- ブラウザーの組織ポリシーが `file://` を禁止する場合は、このフォルダーで `python -m http.server 8765` を実行し、`http://localhost:8765/` を開けます。この検証環境では組織ポリシーによりHTTP経由で検証しました。

## 操作

- 中央の円を押したまま指を動かす：8方向に歩く。横画面では左下へ移動します。
- 雪面の通れる場所をタップ：道を探して移動します。
- 右上のマップ：目的地をタップ、または山小屋・焚き火・集落ボタンで移動します。
- キーボード：矢印キー / WASD。フォーカス可能な方向ボタンもあります。
- 施設の近く：右下の「しらべる」「ひと休み」で案内が出ます。効果や報酬は接続していません。
- 右下の画質：自動 → 軽量 → 標準 → 自動。幅600px以下では自動も初めから軽量です。

## 改善した点

地面と家・木を分離し、建物を立てたまま描画します。足元の位置で前後関係を揃え、主人公が隠れる手前の物体を薄くします。雪面・崖・道は描画済み画像として再利用し、静止時と非表示タブでは更新を止めます。スマホでは描画解像度を抑え、約30回／秒を上限にして負荷を減らします。

実行用画像6枚は **580,718 bytes（約567KiB）**。生成PNG原画を実行時に読み込むことはありません。主人公は本体の絵を読み取り、試作専用の小さな複製を作りました。

## 検証

`qa/verify.cjs` の26項目が成功。方向変更、斜め移動、指を離す・キャンセル・フォーカス喪失時の停止、壁と角抜け、タップ移動、峠を回る集落への経路、施設操作、画質切り替え、静止描画休止、画面はみ出し、主人公と操作パッドの非重複、外部リクエストなし、セーブ書き込みなし、JSエラーなしを確認しました。

390×844 / DPR3 / CPU4倍スロットル / Linux Chromiumソフトウェア描画で、最終版の移動中描画間隔は中央値 **33.3ms**、95パーセンタイル **33.4ms**、50ms超は **0件**。Canvas描画処理は中央値 **1.4ms**、95パーセンタイル **2.3ms**（`qa/results.json`）。約30fpsの設計に対応する値ですが、実機のGPU・温度・電池・Safariの挙動を保証する測定ではありません。

現行版との同条件比較は `qa/benchmark.json`。この比較の `frames` は独立したrequestAnimationFrameの待ち時間で、実際のCanvas描画回数とは異なります。試作の描画頻度は `qa/results.json` の値を参照してください。

画面サイズ：320×568、390×844、844×390、1365×900。最終画面は `qa/*-final.png` と `qa/small-phone.png`。初回は `qa/*-v1.png`、現行版は `qa/baseline-hd2d.png`。
