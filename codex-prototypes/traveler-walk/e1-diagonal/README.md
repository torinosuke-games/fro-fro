# e1 ななめ歩行シート（第3弾・確認用）

`SPRITE_REQUESTS_3.md`に基づくe1だけの候補。成果物：`img/adventure/travelers/e1-wd.png`。2048×2048・透明RGBA・4列×4行、各512×512。

行は左前・右前・左後ろ・右後ろ。列は右足接地・通過・左足接地・逆足通過。`e1.png`・`e1-d.png`・承認済み`e1-w.png`の3枚を参照し、ななめの立ち姿の45度の向きと衣装、歩く絵の足の動き・大きさ・線を合わせた。

4方向を一列ずつ生成。初回の逆足の姿勢、左向きの髪の差し色・ポーチの見え方、左後ろの接地と通過の足幅を見直して再生成した。採用コマを切り出し、人物高400px・足の裏472px・頭の左右の中心をそろえて配置。隣のコマの断片が切り出しに入った場合は、主な連結した人物領域の外接枠で範囲を絞った。描画による修正や人物全体の左右反転は行っていない。

全16コマの高さ400px、接地線472px、枠からのはみ出しなしを確認。4行すべてで、接地コマのブーツの外形幅が通過コマより15px以上広いことを測定した。測定は枠の下側82pxの茶色の画素を使い、紫のマフラーや赤い輪郭の微小な断片を除外する。これは画像の変更ではなく検証用の色判定で、足首間距離ではない。人物の一致・左右の足と腕の前後関係・歩行ループの最終判断は目視で行う。

`review.html`は160px・80pxで4方向を再生し、停止・コマ送りできる。承認済みの歩く絵とななめの立ち姿への比較リンクを付けた。390×844のChromiumで画像読み込み・8プレビュー・全4コマ・正しい方向表示・ページエラーなしを確認。

採用した16コマは`frame-*.png`。再組み立て：リポジトリのルートで`node codex-prototypes/traveler-walk/tools/assemble-walk.cjs codex-prototypes/traveler-walk/e1-diagonal/assembly-input.json`。`prompts.json`は生成指示、`crops.json`と`trims.json`は切り出しの記録、`results.json`は測定結果。

e1の確認待ち。残り13人のななめ歩行画像は、OK後に作成する。WebP化・ゲームへの取り込みは依頼書に従いClaude側で行う。
