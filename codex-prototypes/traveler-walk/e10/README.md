# e10 歩行シート

成果物：`img/adventure/travelers/e10-w.png`。2048×2048・透明RGBA・4列×4行、各512×512。

行は前・後ろ・左・右、各4コマは接地・通過・逆足接地・逆足通過。e10の立ち姿と承認済みe1を参照し、黒い高いポニーテール、赤いマント、銀と金の鎧、革ベルトと腰の赤い布、装甲靴を合わせた。

参照画像は必要な方向だけを小さくして入力。4方向を別々に生成後、正面4列目と左4列目の支持足の重複を単独コマで修正。正面4列目は取り込み済みe2の通過姿勢も見本にした。

人物の切り出し・拡縮・配置で全16コマの人物高400px、足の裏472pxに統一。描画による修正や人物全体の左右反転は行っていない。`assembly-input.json`は採用画像、`prompts.json`は生成指示、`results.json`は各コマの測定記録。

左右の接地と通過で足の開閉を確認。bootSpanは下端の不透明な外形幅で、マントを含む場合があり、足首間距離ではない。衣装の細部、腕と足の前後関係、歩幅の最終判断は目視で行う。

`review.html`は160pxと80pxで4方向を再生し、停止・コマ送りできる。390×844のブラウザーでPNG読込・全4コマ・8プレビュー・操作・ページエラーなしを確認。実機確認、WebP化とゲームへの組み込みはClaude側で行う。
