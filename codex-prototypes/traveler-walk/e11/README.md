# e11 歩行シート

成果物：`img/adventure/travelers/e11-w.png`。2048×2048・透明RGBA・4列×4行、各512×512。

行は前・後ろ・左・右。各4コマは接地・通過・逆足接地・逆足通過。e11の立ち姿と承認済みe1を参照し、銀髪、茶色のフードと裾が裂けたマント、黒い服、革ベルトとブーツ、青緑の耳飾りを合わせた。

入力と確認画像の合計サイズを抑えるため、立ち姿は各方向512×512、e1は該当行1024×256に縮小して使用。4方向を生成し、正面は足の順序を再確認して採用。左右4列目を単独コマで修正し、支持足と靴先を見直した。左向きに混ざった白い布も再生成で除いた。

人物の切り出し・拡縮・配置で16コマの人物高400px、足の裏472pxに統一。描画による修正や人物全体の左右反転は行っていない。`assembly-input.json`が採用画像、`prompts.json`が生成指示、`results.json`が測定結果。

左右の接地・通過で足の開閉を確認。bootSpanは下端の不透明な外形幅でマントも含む場合があるため、足首間距離ではない。衣装細部、腕と足の前後関係、歩幅の最終判断は目視で行う。

`review.html`は160pxと80pxで4方向を再生し、停止・コマ送りできる。390×844のブラウザーでPNG読込・全4コマ・8プレビュー・格子背景・操作・ページエラーなしを確認。実機確認、WebP化とゲームへの組み込みはClaude側で行う。
