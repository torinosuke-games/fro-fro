# e12 歩行シート

成果物：`img/adventure/travelers/e12-w.png`。2048×2048・透明RGBA・4列×4行、各512×512。

行は前・後ろ・左・右。各4コマは接地・通過・逆足接地・逆足通過。e12の立ち姿と承認済みe1を参照し、白銀の長い髪、青い目、紺色の魔法帽と革の帯、金の星模様のコート、白いフリル服、革ベルトとブーツを合わせた。

入力画像の合計量を抑えるため、小さい立ち姿と必要な方向だけのe1歩行見本を使用。4方向の初回生成を見直し、正面1/4列目・左4列目を単独コマで修正。後ろ向きはその方向の立ち姿を主参照にして、帽子の帯とバックルの見え方を再生成。正面4列目は取り込み済みe2の通過姿勢も見本にした。

人物の切り出し・拡縮・配置で全16コマの人物高400px、足の裏472pxに統一。描画による修正や全体の左右反転は行っていない。`assembly-input.json`は採用画像、`prompts.json`は生成指示、`results.json`は測定結果。

左右の接地・通過で足の開閉を確認。bootSpanは下端の不透明な外形幅で、衣装や髪を含む場合もあり、足首間距離ではない。衣装細部・腕と足の前後関係・歩幅の最終判断は目視で行う。

`review.html`は160pxと80pxで4方向を再生し、停止・コマ送りできる。390×844のブラウザーでPNG読込・全4コマ・8プレビュー・格子背景・操作・ページエラーなしを確認。実機確認、WebP化とゲームへの組み込みはClaude側で行う。
