- 行：前／後ろ／左／右。列：右足接地／通過／左足接地／逆足通過。

## 作成と修正

4方向を1行4コマずつ画像生成し、透明領域の切り出し・リサイズ・配置でシートを組み立てました。絵の描画や足のポーズの修正は画像生成ツールで行っています。

初稿から、背面のマントの反転、肩の防具の左右、歩幅、前向き4コマ目の接地足を再生成・修正しました。背面は立ち姿の背面だけを切り出した参考画像も追加して、見える肩当ての側とマントを合わせています。

`prompts.json`、`revisions.json`、`final-corrections.json`、`back-prompt-final.json` に使用した指示を記録しています。`assembly-input.json` の生成元ファイルは実行環境内の中間画像です。配布画像は完成PNGの1枚です。

e2は先行確認用です。残り12人は依頼書のe2確認手順に合わせて進めます。e1の画像と本編コード・WebP・保存形式は変更していません。
