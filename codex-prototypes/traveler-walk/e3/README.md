# e3 歩行シート

成果物：`img/adventure/travelers/e3-w.png`。2048×2048、透明RGBA、4列×4行、各512×512。

上から前・後ろ・左・右。列は接地・通過・逆足接地・逆足通過。人物高400px、足の裏472pxにそろえた。各方向の立ち姿を主参照、e1-w.pngを動作見本に使用。正面4列目はe2の取り込み済み通過姿勢も参考にした。

## 作成と見直し

- 4方向を別々に生成し、人物・衣装・背中の楽器を確認。
- 左向きの歩幅を修正し、左右の接地と通過で足の開閉を明確化。
- 正面・後ろの足の重複と横向きの逆側の通過姿勢を、単独コマで再生成。
- 正面3列目の再生成は足の入れ替えが反映されなかったため不採用。初回の正面1列目を3列目に配置し、修正した逆足の接地コマを1列目に使用。
- 生成画像の切り出し・拡縮・配置だけで最終シートを組み立て。描画による修正や全体の左右反転は行っていない。

`prompts.json`は生成指示（不採用の試行を含む）、`assembly-input.json`は最終採用画像の対応、`results.json`は画像仕様と各コマの測定記録。

## 確認

画像寸法・透明度・16コマ・高さ400px・足の裏472px・セル内への収まり・左右の開閉を確認。下端の靴の外形幅は接地コマの方が通過コマより広い（足首間距離の測定ではない）。80px表示で足の開閉も目視確認。

`review.html`は4方向を160pxと80pxで再生し、停止・コマ送りできる独立確認ページ。390×844のブラウザーで画像読込・操作・エラーなしを確認。実機確認、衣装の細部・足の前後関係の最終判断、WebP化とゲームへの組み込みはClaude側で行う。
