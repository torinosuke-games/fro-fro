# e4 ななめ歩行シート

SPRITE_REQUESTS_3.md と e1 のOK後の依頼に基づく確認用画像。成果物：img/adventure/travelers/e4-wd.png。2048×2048・透明RGBA・4列×4行、各512×512。

行は左前・右前・左後ろ・右後ろ。列は右足接地・通過・左足接地・逆足通過。e4.png・e4-d.png・e4-w.png の3枚を確認して参照し、承認済み e1-wd.png も動き・大きさの見本にした。

方向ごとに一列を生成し、採用コマを切り出して拡縮・配置。全16コマの人物高400px・接地線472px・頭の左右の中心を統一。隣のコマの微小な断片が入った場合は、主な連結した人物領域の外接枠で切り出し範囲を絞る。人物全体の左右反転や手描きの姿勢修正は行っていない。

4方向すべてで接地と通過の足の開閉を確認し、後ろ向きの通過では浮いたブーツが見えるよう指示した。全16コマの高さ・足の裏の線・枠からのはみ出しなし、各行で接地のブーツの外形幅が通過より15px以上広いことを測定。測定幅は足首間距離ではない。茶色のブーツの測定ではマントなどを除外する色判定を使い、画像そのものは変更しない。衣装細部・左右の足と腕の前後関係・ループの最終判断はClaudeの目視確認で行う。

review.html は160pxと80pxの再生・停止・コマ送り、立ち姿と上下左右の歩く絵への比較リンク。390×844のChromiumで画像読み込み・8プレビュー・全4コマ・方向表示・ページエラーなしを確認。

frame-*.png は採用した16コマ。再組み立てはリポジトリのルートで node codex-prototypes/traveler-walk/tools/assemble-walk.cjs codex-prototypes/traveler-walk/e4-diagonal/assembly-input.json。prompts.json は生成指示、crops.json は切り出し記録、results.json は検証結果。WebP化とゲームへの取り込みはClaude側で行う。

## 今回の見直し

4列目の逆足の通過を単独コマで再生成。e1 の対応する通過コマを姿勢の参考、自分の立ち姿・歩行シートを衣装の参考とし、左右の支持足を入れ替えた。後ろ向きは上げたブーツの靴底がはっきり見える。4コマ一列の再試行は足の入れ替えと足幅に不足があり不採用。高さ・接地線・全4行の足幅の差と確認ページの操作を再確認した。
