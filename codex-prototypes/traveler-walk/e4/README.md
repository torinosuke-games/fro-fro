# e4 歩行シート

成果物：`img/adventure/travelers/e4-w.png`。透明RGBA・2048×2048・4列×4行、各512×512。

行は前・後ろ・左・右。列は右足接地・通過・左足接地・逆足通過。立ち姿e4の各方向を主参照、承認済みe1を動作見本に使用した。赤い髪・ゴーグル・革コート・襟と袖の毛皮・ベルトとブーツを参照。

## 見直し

4方向を生成後、後ろ向きの通過コマの支持足を修正。横向きの接地・通過を個別に修正し、さらに左右の行を短い歩幅へ再生成した。正面の接地コマ1・3は初回生成の順序を入れ替えて配置。全体の左右反転や手描きの修正は行っていない。

生成した人物を切り出し・拡縮・配置し、16コマを人物高400px、足の裏472pxにそろえた。`assembly-input.json`が最終採用画像、`prompts.json`が試行を含む生成指示、`results.json`が寸法・透明度・各コマの測定結果。

左右とも接地で足を開き、通過で閉じる差を確認。測定値のbootSpanは下端の靴の外形幅であり、足首間距離ではない。歩幅や足の前後関係、衣装の細部は最終的に目視で判断する。

`review.html`で4方向を160px・80px表示、停止とコマ送りが可能。390×844のブラウザーでPNG読込・表示・操作・ページエラーなしを確認。実機での確認、WebP化、ゲームへの組み込みはClaude側で行う。
