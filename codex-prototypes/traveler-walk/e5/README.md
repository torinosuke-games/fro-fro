# e5 歩行シート

成果物：`img/adventure/travelers/e5-w.png`。2048×2048・透明RGBA・4列×4行、各512×512。

上から前・後ろ・左・右。接地・通過・逆足接地・逆足通過の4コマ。立ち姿e5の各方向と承認済みe1の歩行を参照し、紺色の髪・丸眼鏡・青いコート・金ボタン・腰の小瓶とポーチ・ブーツを合わせた。

## 作成と見直し

4方向を別々に生成。初回の後ろ向きは右向きになったため不採用。前と後ろは、各方向だけを切り出したe1の動作見本で再生成。正面4列目・後ろ3列目・左4列目は、足の入れ替えを単独コマで修正した。正面4列目は取り込み済みe2の通過姿勢も参考にした。

右2列目に隣の靴の断片が入っていたため、セル左側の切り出し範囲を40px詰め、当該人物だけを配置した。描画による修正や人物全体の左右反転は行っていない。

`assembly-input.json`は最終採用画像の対応、`prompts.json`は不採用を含む生成指示、`results.json`は16コマの寸法・接地・透明度の記録。切り出し・拡縮・配置で人物高400px、足の裏472pxに統一した。

左右とも接地コマは足を開き、通過コマは閉じる差を確認。bootSpanは下端の靴の外形幅であり、足首間距離ではない。歩幅や足の前後関係、衣装の細部の最終判断は目視で行う。

`review.html`は160pxと80pxで4方向を再生し、停止・コマ送りが可能。390×844のブラウザーで読込・操作・ページエラーなしを確認。実機確認、WebP化とゲームへの組み込みはClaude側で行う。
