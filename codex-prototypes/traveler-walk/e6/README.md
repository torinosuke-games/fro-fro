上から前・後ろ・左・右。右足の接地・通過・左足の接地・逆足の通過の4コマ。e6の立ち姿の各方向を主参照、承認済みe1を歩行見本に使用。白と金のフード・ローブ、茶色の巻き髪、リボン、赤い留め具、金の模様とブーツを参照した。

## 作成と見直し

4方向を別々に生成。ローブの長さを保ち、裾の下でブーツが開閉するよう指示した。初回生成後、全方向の足の順序と輪郭を再生成で見直し。正面4列目・後ろ3列目・左右4列目を単独コマで再修正した。正面4列目は、取り込み済みe2の通過姿勢も参考にした。

後ろのフードより上に残った点が人物高に含まれないよう、人物本体の上端を基準に矩形で切り出した。切り出し範囲は`crops.json`に記録。描画による修正や人物全体の左右反転は行っていない。

生成人物の切り出し・拡縮・配置で、16コマの人物高400px、足の裏472pxに統一。`assembly-input.json`が最終採用画像、`prompts.json`が生成・修正指示、`results.json`が仕様と各コマの測定結果。

左右の接地コマで足を開き、通過コマで閉じる差を80px表示でも確認。bootSpanは下端の不透明な外形幅で、ローブや飾りを含む場合があるため、足首間距離ではない。足の前後関係と衣装細部の最終判断は目視で行う。

`review.html`は4方向を160pxと80pxで再生し、停止・コマ送りできる。390×844のブラウザーでPNG読込・全4コマ・8プレビュー・操作・ページエラーなしを確認。実機確認、WebP化、ゲームへの組み込みはClaude側で行う。
