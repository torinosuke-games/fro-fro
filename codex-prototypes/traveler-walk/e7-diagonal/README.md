# e7 ななめ歩行シート

SPRITE_REQUESTS_3.md とユーザーの依頼に基づく確認用画像。成果物：`img/adventure/travelers/e7-wd.png`。2048×2048・透明RGBA・4列×4行、各512×512。

行は左前・右前・左後ろ・右後ろ。列は右足接地・通過・左足接地・逆足通過。`e7.png`・`e7-d.png`・`e7-w.png` の3枚を目視確認して参照し、承認済み e1 のななめ歩行も姿勢・動きの参考にした。人物の髪・衣装・持ち物は自分の3枚から指定。

生成画像から採用コマを切り出して拡縮・配置する、e1 と同じ組み立て方法。16コマの人物高400px・接地線472px・頭の左右の中心を統一。隣のコマの断片は主な連結人物領域の外接枠で切り出し範囲を絞る。人物全体の左右反転や描画による姿勢修正は行わない。

4方向の接地と通過の足の開閉、後ろ向きで浮いた靴底が見えることを確認。寸法・透明度・16コマの高さと接地線・枠内への収まり、各行の接地のブーツ外形幅が通過より15px以上広いことを既存の assemble-walk.cjs で検証。測定幅は足首間距離ではない。衣装細部・左右の足と腕の前後関係・歩行ループの最終判断はClaudeの目視確認で行う。

`review.html` は160pxと80pxで4方向の再生・停止・コマ送り、立ち姿と上下左右の歩く絵への比較リンク。390×844のChromiumで画像読み込み・8プレビュー・全4コマの操作・方向表示・リンク・ページエラーなしを確認。

`frame-*.png` は採用した16コマ。再組み立て：リポジトリのルートで `node codex-prototypes/traveler-walk/tools/assemble-walk.cjs codex-prototypes/traveler-walk/e7-diagonal/assembly-input.json`。`prompts.json` は生成指示、`crops.json` は切り出し記録、`results.json` は検証結果。WebP化とゲームへの取り込みはClaude側で行う。
