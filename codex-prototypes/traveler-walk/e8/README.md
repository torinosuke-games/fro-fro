# e8 歩行シート

成果物：`img/adventure/travelers/e8-w.png`。透明RGBA・2048×2048・4列×4行、各512×512。

行は前・後ろ・左・右。列は接地・通過・逆足接地・逆足通過。e8の立ち姿と承認済みe1を参照し、金髪・銀と金の鎧・青い布と白い模様・ベルト・装甲靴を合わせた。

4方向を別々に生成後、正面1/4列目、後ろ2/3列目、左右4列目を単独コマで再生成し、足の重複と支持足を見直した。正面4列目は取り込み済みe2の通過姿勢も見本にした。人物の外に残った断片は矩形の切り出し範囲で除外した（`crops.json`）。描画による修正や全体の左右反転は行っていない。

切り出し・拡縮・配置で16コマの人物高400px、足の裏472pxに統一。`assembly-input.json`が採用画像、`prompts.json`が生成指示、`results.json`が各コマの測定結果。左右の接地・通過で足の開閉を確認。bootSpanは靴の外形幅であり、足首間距離ではない。衣装細部・足の前後関係・歩幅の最終判断は目視で行う。

`review.html`で4方向を160pxと80pxで再生し、停止・コマ送りが可能。390×844のブラウザーでPNG読込・全4コマ・8プレビュー・操作・ページエラーなしを確認。実機確認、WebP化、ゲームへの組み込みはClaude側で行う。
