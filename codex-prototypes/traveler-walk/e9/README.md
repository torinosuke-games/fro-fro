# e9 歩行シート

成果物：`img/adventure/travelers/e9-w.png`。2048×2048・透明RGBA・4列×4行、各512×512。

行は前・後ろ・左・右、各4コマは接地・通過・逆足接地・逆足通過。e9の立ち姿と承認済みe1を参照し、橙色のお団子髪、赤と金の刺繍服、黒いゆったりしたズボン、赤と金のベルト付きブーツを合わせた。

入力画像の合計サイズを抑えるため、立ち姿は必要な方向を512×512、e1は該当する行を1024×256に縮小して使用。4方向を生成後、正面1列目・後ろ3列目・左右4列目を単独コマで修正し、足の重複と支持足を見直した。

人物の切り出し・拡縮・配置で16コマの人物高400px、足の裏472pxに統一。描画による修正や全体の左右反転は行っていない。`assembly-input.json`は採用画像、`prompts.json`は生成指示、`results.json`は測定結果。

左右の接地で足を開き、通過で閉じる差を確認。bootSpanは下端の靴の外形幅で、足首間距離ではない。衣装細部・足の前後関係・歩幅の最終判断は目視で行う。

`review.html`は160pxと80pxで4方向を再生し、停止・コマ送りが可能。390×844のブラウザーでPNG読込・全4コマ・8プレビュー・操作・ページエラーなしを確認。実機確認、WebP化とゲームへの組み込みはClaude側で行う。
