# j4 ななめ歩行シート

SPRITE_REQUESTS_3.md とユーザーの依頼に基づく確認用画像。成果物：`img/adventure/travelers/j4-wd.png`。2048×2048・透明RGBA・4列×4行、各512×512。

行は左前・右前・左後ろ・右後ろ。列は右足接地・通過・左足接地・逆足通過。`j4.png`・`j4-d.png`・`j4-w.png` の3枚を目視確認して参照し、承認済み e1 のななめ歩行を姿勢の参考にした。銀灰色の短い髪と青緑の差し色、耳飾り、フードを下げた茶色のマントと金の刺繍・背面の模様、暗色の服、手甲と黒い手袋、革のブーツを合わせた。

e1 の採用コマを歩行段階ごとの2×2の見本に並べ、4段階を画像生成した。2・3列目の露出した指を、参考画像と同じ黒い手袋に画像生成ツールで修正。採用16コマを人物の主な連結領域の外接枠で切り出し、拡縮・配置する、e1 と同じ組み立て方法。人物高400px・足の裏472px・頭の左右の中心を統一。人物全体の左右反転や描画による姿勢修正は行っていない。

4方向の接地と通過の足の開閉、後ろ向きで浮いた靴底が見えることを目視確認。寸法・透明度・高さ・接地線・枠内への収まりを既存の assemble-walk.cjs で検証した。各行の接地の下端外形幅は通過より15px以上広い。全16コマでセル内 y390 以降の茶色画素を測定する。測定幅は衣装を含む場合があり、足首間距離ではない。衣装細部・足と腕の前後関係・ループの最終判断はClaudeの目視確認で行う。

`review.html` は160pxと80pxで4方向の再生・停止・コマ送り、立ち姿と上下左右の歩く絵への比較リンク。390×844のChromiumで画像読み込み・8プレビュー・全4コマの操作・方向表示・リンク・ページエラーなしを確認。検証記録は `review-checks.json`。

`frame-*.png` は採用した16コマ。再組み立て：リポジトリのルートで `node codex-prototypes/traveler-walk/tools/assemble-walk.cjs codex-prototypes/traveler-walk/j4-diagonal/assembly-input.json`。`prompts.json` は生成指示と手袋の修正指示、`crops.json` は切り出し記録、`results.json` は測定結果。WebP化とゲームへの取り込みはClaude側で行う。
