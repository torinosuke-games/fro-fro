# j4 歩行シート

成果物：`img/adventure/travelers/j4-w.png`。2048×2048・透明RGBA・4列×4行、各512×512。前・後ろ・左・右の順。

j4の立ち姿と承認済みe1を参考に生成。銀灰色の髪、青緑の差し色と耳飾り、金縁の暗いフード付きマント、革ベルト、金属の腕当て、黒いブーツを合わせた。初回生成の逆足の姿勢を修正し、採用した各コマを切り出して配置した。正面4コマ目は通過姿勢の横一列を再生成し、その1コマを採用。単独コマの生成は背景の光や体の比率が合わず不採用。

生成画像の行間は等分線からずれていたため、列ごとの透明な行間で切り出した。主な連結した人物領域の外接枠で、隣の行の断片を切り出し範囲から除いた。拡縮・配置で人物高400px、接地線472pxに統一。人物全体の反転や手描き修正は行っていない。

採用した入力画像はこのフォルダーに保存。`assembly-input.json`と既存の`../tools/assemble-walk.cjs`で再組み立てできる。`prompts.json`は生成指示、`results.json`は寸法と左右の開閉の測定結果。bootSpanは衣装を含む下端の外形幅で、足首間距離ではない。

390×844のChromiumでPNG読み込み、8プレビュー、全4コマのコマ送り、ページエラーなしを確認。足の前後関係・衣装細部・歩行ループの最終確認とWebP化・ゲームへの取り込みはClaude側で行う。
