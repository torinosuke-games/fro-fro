# j6 歩行シート

成果物：`img/adventure/travelers/j6-w.png`。2048×2048・透明RGBA・4列×4行、各512×512。行は前・後ろ・左・右、列は接地・通過・逆足接地・逆足通過。

j6の立ち姿と承認済みe1の歩行見本を、方向ごとに切り出して参照。赤い長いポニーテール、金茶色の目、金模様の銀鎧、黒い下着と手袋、金模様の赤い服、革ベルト、黒と金の鞘を合わせた。4方向を一列ずつ生成し、正面4列目・後ろ2列目の逆足、左3列目・右1列目の接地と腕振り、右2列目の閉じた通過姿勢を修正した。

生成画像をコマごとに切り出し、拡縮・配置で全16コマの人物高400px、足の裏472pxに統一。正面4列目の切り出しでは、主な連結した人物領域の外接枠を使って隣の人物の小さな断片を範囲から除いた。描画による修正や人物全体の左右反転は行っていない。

採用した16コマはこのフォルダーの`frame-*.png`。`assembly-input.json`と`../tools/assemble-walk.cjs`で再組み立てできる。`crops.json`は切り出しの履歴、`prompts.json`は生成指示、`results.json`は測定結果。左右の接地・通過の開閉を確認。bootSpanは衣装を含む下端の不透明な外形幅で、足首間距離ではない。人物・衣装細部・腕と足の前後関係・ループの最終判断は目視で行う。
