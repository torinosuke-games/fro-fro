# 雪原の冒険の画像

今回の試作専用に画像生成で制作したオリジナル素材。参考画像そのものや既存ゲームのキャラクターは使用していない。

- `snow-world.png`: 雪の海岸・針葉樹林・峠・町・焚き火を描いた見下ろしマップ。`FF.adventure.MAP` の13×9マスと施設座標から描いたガイドを元に生成。表示は936×648の座標系、移動判定は既存のマップ。小さな草・石・雪の起伏は装飾で通行可能。
- `snow-battle.png`: 昼の雪原・山・湖を描いた正面戦闘背景。
- `snow-enemies.png`: アルファ付きの敵3体の画像。`js/svg/adventure-world.js` が各領域をSVGのviewBoxで切り出して表示する。元画像の左から雪かじりの野獣、霜牙のオオカミ、氷角の大獣。

マップの主人公は `travelers/<avatar>-<direction>.svg` のオリジナルの32×48ピクセルスプライト。小学生用12人・中学生用12人に上下左右を用意（96枚）。設定の肖像画から髪型・服・帽子・眼鏡などの特徴を取り入れた。`node tools/build-adventure-travelers.cjs` で再生成できる。地形画像が取得できない場合は、移動マップから描いたCanvasの簡易地形を代わりに表示する。新しい外部ライブラリ・外部画像配信への依存はない。
