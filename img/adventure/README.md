# 雪原の冒険の画像

今回の試作専用に画像生成で制作したオリジナル素材。参考画像そのものや既存ゲームのキャラクターは使用していない。

- `snow-world.png`: 雪の海岸・針葉樹林・峠・町・焚き火を描いた見下ろしマップ。`FF.adventure.MAP` の13×9マスと施設座標から描いたガイドを元に生成。表示は936×648の座標系、移動判定は既存のマップ。小さな草・石・雪の起伏は装飾で通行可能。
- `snow-battle.png`: 昼の雪原・山・湖を描いた正面戦闘背景。
- `snow-enemies.png`: アルファ付きの敵3体の画像。`js/svg/adventure-world.js` が各領域をSVGのviewBoxで切り出して表示する。元画像の左から雪かじりの野獣、霜牙のオオカミ、氷角の大獣。

マップの主人公は `travelers/e1.png`〜`e12.png` の高精細な生成画像。各シートは正面・後ろ・左・右の2×2配置で、1方向あたり627×627px。元の32×48pxスプライトを描き直し、設定の肖像画から髪・衣服・帽子・装備を再現した。CSSで該当方向の四分の一を表示するので、拡大した低解像度の絵にはならない。

中学生の12候補も同じキャラクターに対応するシートを使う。姿の違う灰青髪の旅人と赤髪の騎士には `j4.png`・`j6.png` を別に制作（計14枚・56方向の原画）。中学生用の対応は `js/svg/adventure-world.js` の `traveler`。

各シートは透明PNG。ゲーム中は選択された主人公の1枚だけを読み込む。新しい外部ライブラリ・外部画像配信への依存はない。地形画像が取得できない場合は、移動マップから描いたCanvasの簡易地形を代わりに表示する。
