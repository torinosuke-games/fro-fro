# 手動確認の手順（tests/MANUAL.md）

画面を操作しないと確かめられない項目の確認手順です。
ロジックだけで確かめられる項目は `node tests/run.js` で自動テストしています（一覧は末尾）。

## 準備

- `index.html` をダブルクリックして開きます（`file://`）。サーバーは不要です。
- 時間を進める・資源を足すなどのテスト操作は、URL の末尾に `?debug=1` を付けて開いたときの「デバッグ画面」で行います。
  - 例：`file:///C:/…/frozen-frontier/index.html?debug=1`
  - 画面左下の **DEBUG** の札、または 設定 → 「デバッグ画面」から開けます。
- 最初からやり直すときは、デバッグ画面の「今すぐリセット」を使います。
- スマートフォンの縦画面は、PC のブラウザの開発者ツールのデバイス表示（幅 390〜412px 程度）でも確認できます。

各項目の「□」に、確認できたら ✓ を付けてください。
